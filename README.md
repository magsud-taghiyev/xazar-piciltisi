# Xəzər Pıçıltısı

> **AI-assisted vibe-coding portfolio project.** This site was created with AI tools from a project brief and creative direction. It is not presented as code written entirely by the owner.

A fictional boutique cabin retreat concept set between Nabran’s pine forest and the Caspian Sea. Azerbaijani is the default language, with Russian and English options.

## Project highlights

- Responsive React website with subtle motion
- Azerbaijani, Russian, and English language options
- Cabin cards, photo gallery, FAQs, and a sample booking flow
- Custom logo and visual identity
- AI-assisted imagery created for the concept

## Portfolio disclaimer

This is a design and coding concept, not a real hotel booking service. Property details, prices, availability, amenities, and location information are illustrative. The booking form demonstrates an interaction only; it does not send or store guest information.

## Stack

React 19 · TypeScript · TanStack Start · Tailwind CSS · Bun · Cloudflare Workers

## Run locally

```sh
bun install
bun run dev
```

Create a production build with `bun run build`. The live concept is hosted at [xazar-piciltisi.xezernagmesi.workers.dev](https://xazar-piciltisi.xezernagmesi.workers.dev/).
